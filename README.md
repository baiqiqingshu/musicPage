# 🎵 云音乐播放器 - Cloudflare Worker版

基于 **Cloudflare Worker** 构建的现代化在线音乐播放器，集成了完整的前端应用代码，支持多平台音乐搜索和在线播放。

> **⚠️ 重要提醒**: 本项目仅用于技术学习和交流，请勿用于商业用途。所有音乐内容版权归原作者所有，使用前请确保符合当地法律法规。

## 📋 版本更新日志

### 独立 HTML 更新（2026-10-25）— 播放模式
- **四种模式**：支持顺序播放、列表循环、单曲循环和随机播放，默认顺序播放；底部控制栏和「待播」列表均可切换。
- **播放规则**：顺序播放到末尾停止，列表循环回到第一首，单曲循环复用音频重播当前歌曲；单曲循环时仍可手动切换歌曲。
- **随机队列**：每轮随机播完所有歌曲，跨轮避免连续播放同一首；「上一首」返回播放历史，再点「下一首」沿历史前进。选择另一首歌或更换队列时重新安排随机顺序，调整音质保留随机历史。
- **记住偏好**：播放模式保存在当前浏览器，刷新后恢复，同源页面同步。切换模式不重置当前歌曲或播放进度。

### 独立 HTML 更新（2026-10-25）— 一屏播放与可收起歌曲列表
- **固定一屏**：默认进入网页全屏，播放信息、歌词和底部控制共用当前视口，页面不再上下滚动；手机和矮屏横向布局自动适配。
- **歌词自动跟随**：当前歌词始终居中，前后歌词在固定区域内平滑切换，无需手动滚动；点击歌词可跳转播放进度，支持键盘操作和减少动态效果。
- **全屏选歌**：顶部「歌曲列表」展开侧栏，可在待播队列、搜索、歌单和收藏之间切换，直接选歌；「收起列表」、遮罩或 Esc 可关闭侧栏。
- **播放连续**：打开、收起列表及切换全屏模式都复用现有音频；重新搜索或修改收藏不会覆盖待播队列。列表打开时 Esc 优先收起列表，再次按下退出网页全屏。

### 独立 HTML 更新（2026-10-24）— 网页全屏与屏幕全屏
- **网页全屏**：独立按钮仅铺满当前网页视口，保留标签栏和地址栏，不调用浏览器全屏 API；默认进入此模式。
- **屏幕全屏**：另一个独立按钮显式请求浏览器原生全屏，支持时隐藏浏览器界面。两种模式均展示大封面、播放控制和同步歌词，并适配手机。
- **不中断音乐**：复用原有音频和控件，进入、退出不会重载歌曲或重置进度，收藏、音质及下载仍可使用。
- **退出与兼容**：两种模式均支持退出按钮和 Esc；浏览器不支持或拒绝屏幕全屏时，明确转为网页全屏。
- **可访问交互**：全屏期间限制背景滚动和焦点，退出恢复之前的位置与焦点；现已改为矮屏一屏布局，退出按钮保持可达。

### 独立 HTML 更新（2026-10-24）— 界面重设计与歌曲收藏
- **全新布局**：暖白曲库与深绿播放器，桌面双栏，手机纵向排列；通过顶部导航定位曲库、播放器和歌词，不再依赖横滑切页。
- **歌曲收藏**：搜索结果、导入歌单和播放器均可一键收藏或取消；在「我的收藏」中直接播放。
- **本地持久化**：收藏按音乐来源与歌曲 ID 区分，刷新保留，同源页面自动同步；只保存歌曲信息，不保存音频文件或临时播放链接。
- **播放互不干扰**：重新搜索、切换曲库视图或取消收藏不会替换当前播放队列；下载按钮始终对应所在行的歌曲。
- **交互优化**：搜索加载与错误提示、歌曲计数、键盘操作、播放进度可访问标签及减少动态效果支持。

本次更新仅适用于 `music.html`；`worker.js` 的独立界面与功能保持不变。单页无需安装依赖或执行构建，保存文件后重新打开或刷新即可使用。

## 🚀 快速开始

### 🎯 两种使用方式

#### 方式一：独立HTML版本（推荐新手）
1. **下载文件**
   - 直接下载 `music.html` 文件
   
2. **直接使用**
   - 在浏览器中打开 `music.html` 文件
   - 无需任何配置，即可开始使用

**全屏播放**
- 默认打开网页全屏，保留浏览器标签栏和地址栏；播放器、歌词及底部播放控制固定在一屏内，页面不滚动。
- 点击顶部「歌曲列表」打开侧栏，可搜索歌曲、导入歌单、播放收藏，或从「待播」队列切歌。选歌后列表保持打开，方便连续选择；点击「收起列表」或遮罩返回歌词。
- 歌词自动跟随播放居中，无需滚动。点击歌词跳转至该句；聚焦当前歌词后，按上下方向键切换前后句，Enter/空格确认跳转。
- 如需隐藏浏览器界面，点击顶部「屏幕全屏」。只有这个入口会请求原生全屏，进入后仍能打开歌曲列表。
- 点击顶部「退出」返回曲库布局，当前音乐继续播放。网页全屏下，Esc 优先收起已打开的列表，再次按下退出全屏；屏幕全屏下 Esc 同时遵循浏览器原生退出行为。
- 手机及其他浏览器的原生全屏能力取决于浏览器；不支持或未获授权时会提示并转为网页全屏，不影响直接使用「网页全屏」。

**播放模式**
- 在底部播放按钮左侧，或「歌曲列表 → 待播」中选择模式，两处选择保持同步。
- **顺序播放**：按队列顺序播放，最后一首结束后停止。
- **列表循环**：最后一首结束后继续播放第一首，手动上一首、下一首也可首尾切换。
- **单曲循环**：歌曲结束后从头重播，手动上一首、下一首仍可切歌。
- **随机播放**：每轮随机播完所有歌曲，避免相邻重复；上一首返回听过的歌曲，下一首优先沿播放历史前进。
- 模式保存在 `localStorage`（键：`musicPage.playbackMode.v1`），刷新后保留。只有一首歌时，顺序播放结束即停止，其余模式继续重播。

**收藏使用**
- 搜索歌曲或导入网易云歌单，点击歌曲旁的爱心；也可在播放器中收藏当前歌曲。
- 点击「我的收藏」查看、播放或取消收藏；取消正在播放的收藏不会停止音乐。
- 收藏保存在当前浏览器的 `localStorage`（键：`musicPage.favorites.v1`），不会上传到服务器，也不会跨设备同步。清除站点数据会删除收藏；浏览器禁用存储或空间不足时页面会明确提示。
- 建议通过固定本地地址使用，例如运行 `py -m http.server 4173` 后打开 `http://localhost:4173/music.html`。直接打开文件时，本地存储行为取决于浏览器；切换协议、域名或端口会使用不同的收藏空间。
- 歌单导入支持歌单 ID 或包含 `id=` 的网易云链接。歌曲与歌词仍需联网获取。
- 键盘：聚焦歌曲名称后按 Enter/空格播放；聚焦进度条后用方向键调整 5 秒，Home/End 跳到开头/结尾。焦点不在控件中时，空格切换播放，左右方向键切歌。

#### 方式二：Cloudflare Worker版本

### 📋 前提条件

- 安装 [Node.js](https://nodejs.org/) (版本 16 或更高)
- 安装 [Wrangler CLI](https://developers.cloudflare.com/workers/wrangler/install-and-update/)
- 拥有 [Cloudflare](https://cloudflare.com/) 账户

### 🔧 部署步骤

1. **克隆项目**
```bash
git clone <your-repo-url>
cd musicPage
```

2. **安装 Wrangler CLI**
```bash
npm install -g wrangler
```

3. **登录到 Cloudflare**
```bash
wrangler login
```

4. **配置 Worker 名称**
编辑 `wrangler.toml` 文件中的 `name` 字段：
```toml
name = "your-music-player"  # 修改为你想要的名称
```

5. **部署到 Cloudflare Workers**
```bash
wrangler publish
```

6. **访问你的应用**
部署成功后，访问 `https://your-music-player.<your-subdomain>.workers.dev`

你的音乐播放器现在已经在全球CDN上运行了！

```
├── 移动端交互          # HTML：纵向导航；Worker：横滑切页
├── 音乐播放器          # HTML5 Audio API
├── 歌词同步显示        # 实时解析LRC格式
├── 专辑图片展示        # 动态加载和缓存
├── 音频可视化          # Canvas 2D渲染
├── 动画系统            # CSS过渡 + JavaScript动画控制
└── 用户交互
    ├── 搜索功能         # 多平台音乐搜索
    ├── 播放控制         # 播放/暂停/切换
    ├── 进度控制         # 拖拽定位播放
    ├── 音量调节         # 实时音量控制
    ├── 歌单管理         # 本地存储 + 分享链接解析
    ├── 移动端下拉菜单   # 响应式歌单展示
    ├── 桌面端Tab标签    # 横向歌单导航
    ├── 下载功能         # 音乐/歌词下载
    └── 版本专属交互     # HTML：歌曲收藏；Worker：横滑与触觉反馈
```
